# V1.6 Media Organizer — Security Review Notes (Not a Release Approval)

**Scope:** Draft PR #397, semantic organizer execution and private-media boundary handling.
**Status:** Internal implementation review and synthetic CI evidence. **Independent security review has not occurred.**
**NAS mount tests:** Not performed. Do not merge, deploy or enable execution as a result of this note.

## Synthetic validation evidence

- Deferred cleanup TDD introduced five isolated unit tests for no-delete publication, old-wrapper preservation, immutable manual journal, group conflict fail-closed and changed evidence. Worker integration tests now assert `manual_cleanup_required`, `finalized=false`, retained staged hardlinks and status that does **not** claim zero-change idempotency. A separate RED→GREEN test asserts that deferred manifests cannot enter the legacy automatic publication/retirement paths.


- A separate forged-public-folder test copied a valid owner marker into a replaced empty P/V directory after interrupted promotion. Before the fix the new destination was adopted; with inode receipts it is rejected. A retirement test also proved that cloned markers plus hardlinked contents are insufficient to authorize stage-link deletion.


- Controlled TDD tests verified red before missing exclusion and capability-probe modules were implemented, then green after implementation.
- Destination-swap tests first reproduced an owner marker in an injected foreign directory. The publisher now prepares witnessed groups privately, promotes them with directory NOREPLACE, and checks ownership before each media link. Tested synthetic late-target collision, pending group interruption and post-promotion empty-directory replacement.
- Last-stage-marker gap tests originally required manual intervention. New receipt-backed code permits exact-matching empty-stage recovery; synthetic tests cover valid recovery, forged receipt and replaced stage inode. Worker API test confirms a new admin recovery job can be queued only with valid receipt evidence.
- Additional frozen-stage-swap tests deliberately moved the owned stage directory after owner verification and put a foreign directory (with or without a copied marker) at its original path. The previous mover sent a file to the replacement; the new FD-pinned staging mover refuses that replacement before changing any source file.
- Rejected untrusted stage, foreign target occupancy, changed file identities, interrupted hardlink publication, nested classification cleanup, 200/201 boundary and zero-change repeat scan remain in the focused suite.
- All synthetic tests use temporary directories; media filenames are generic and do not include user private inventories.

**Current special caution:** A namespace-quiescence acknowledgement is an operator assertion, not a mutual-exclusion primitive. Application Worker leases and directory inode validation cannot stop uncooperative SMB/NAS filesystem writers. The new Worker avoids known-unsafe directory deletions by deferring all cleanup, but staged source file movement and public publication still require independent security review and an approved same-mount NAS test. Both flags remain false by default; do not treat cleanup deferral as a release authorization.
