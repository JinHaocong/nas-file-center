# V2 — 一级文件批量重命名（非递归）

## 产品行为

本功能是现有「批量重命名」页面的独立操作模式，与「一级目录批量重命名」及「高级文件重命名」并列。

- 输入：选择一个目录；仅扫描该目录下的直接普通文件。
- 不递归，不改目录名称，不跟随任何文件符号链接，不改变所选目录本身。
- 字面量操作（区分大小写）：名称内替换、名称末尾替换、添加前缀、添加后缀；不将查找文字解释为正则。
- 默认「保留文件扩展名」：操作仅针对最后一个扩展名之前的部分；例如 movie_old.mp4 替换 _old→_new 得到 movie_new.mp4，archive.tar.gz 添加 _v2 后缀得到 archive.tar_v2.gz。
- 关闭保留扩展名后才会修改完整文件名；变更扩展名仅是改名，不做格式转换。
- .env 这种只有前导点的文件名按照没有扩展名处理。
- Preview 只返回变化项。存在占用、大小写折叠重名、不合法目标名称或过长名称时逐项标记冲突，禁用生成 Plan。
- 已有目标名称一律拒绝覆盖，即使目标也在待改名名单内。
- Preview 完全只读；之后生成的只是通用 rename Draft Plan，须走 Freeze → Validate → Worker Execute、安全策略及审计链。

## 限制与验收

- ALLOWED_ROOTS / 隔离区路径策略沿用已有后端。
- no-follow 目录描述符扫描；排除符号链接、特殊文件及目录。
- 每次所选目录最多检查 50,000 个直接条目，超限整次报错。
- 文件身份在扫描与预览期间再次校验；真实执行前仍由现有 Plan 校验保护。
- 测试覆盖同名/大小写冲突、无扩展名、复合扩展名、非法字符、越界、认证、只读及 Draft 计划生成。
- CI 通过不代表 NAS 已部署，也不代表真实 NAS 写入验收完成。
