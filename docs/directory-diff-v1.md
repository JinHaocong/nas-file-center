# V1 — 双目录差异对比（Read-only）

## 本阶段提供
- `/directory-diff`：选择两个互不重叠的根目录，按相对路径递归比较文件及目录条目。
- 类别：仅 A、仅 B、类型不同、文件大小不同、大小相同但未验证内容、两侧均存在的目录。
- 只读：不创建 Plan，不调用 Worker，不做同步、复制、移动、删除或重命名。
- 可筛选对比结果并将当前筛选清单导出 CSV；导出前对潜在表格公式注入进行中和处理。
- 可对单对常规文件显式调用 SHA256 验证，校验相同/不同内容，默认禁止在 Preview 阶段批量计算散列。

## 关键边界
- 必须处于 `ALLOWED_ROOTS` 内，且不能在 `QUARANTINE_ROOT` 下；隔离区内容从扫描中剪枝。
- 两个比较根目录不得相同或存在祖先/子孙关系。
- 根目录和遍历均通过 no-follow 目录描述符，不跟随符号链接；特殊设备文件不参与。
- 每侧扫描上限 10,000 个合格文件/目录条目；超过后返回错误而不是不完整对比。
- 单文件请求式 SHA256 上限 256 MiB，读取前后验证文件身份、大小和修改时间，避免将变化中的内容视为稳定结果。
- Preview 的文件大小相同只能得出 `same_size_unverified`，不能称为内容相同；“双方均有目录”也不能证明目录树一致。
- 数据是即时目录快照，NAS 文件可能同时变化；此结果不是原子快照，也不是备份完整性证明。
- 工作流 CI 可证明源代码测试及 Linux 构建通过；真实 NAS 的大规模性能和文件系统行为需另行验证。

## 后续可能扩展（不属于 V1）
- 对比结果服务器分页/游标（避免大规模条目进入单次 HTTP 响应）。
- 资源策略管控的后台流式对比任务、大文件校验、持久历史清单。
- 差异 → 同步/迁移提案，但必须使用现有 Preview → Draft → Freeze → Validate → Execute 及 no-clobber / PathGuard。
