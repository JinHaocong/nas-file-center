# Third-party UI assets

NAS File Center bundles the following UI assets locally so the web interface works on an offline/LAN NAS without runtime CDN access.

- Bootstrap 5.1.1 — MIT License — https://getbootstrap.com/
- Bootstrap Icons — MIT License — https://icons.getbootstrap.com/

The bundled minified files retain their upstream license headers where provided. NAS File Center does not require external UI asset requests at runtime.
